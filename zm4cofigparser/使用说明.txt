造梦西游4 配置解包工具（zm4_config_unpack.py）

功能：一键完成 SWF 块解压 → XML 导出 → JSON 转换。
依赖：仅 Python 标准库，Python 3.8 及以上。

一、用法
把配置 SWF 放到本目录，运行：
    python zm4_config_unpack.py cg1_20261026_1.swf

指定输出目录：
    python zm4_config_unpack.py cg1_20261026_1.swf output_cg1_20261026_1

默认输出到 output_<文件名>/。每个块导出为 NNN_<表名>.xml.txt，
XML 会再转换成同名的 .json 文件；AMF/二进制块保留 .amf/.bin。

注意：主文件和配置都需要带版本游戏页作 Referer 下载，否则服务器只返回
23 KB 的域名校验占位 SWF；从游戏页正常进入下载即可。版本号和配置日期会
随游戏更新变化，主文件以入口页 game_url_arr[4] 指向的版本页为准。

三、反编译主文件（可选）
主文件是 SWF，可用 FFDec（JPEXS Free Flash Decompiler）反编译为 ActionScript 文件：
项目仓库：https://github.com/jindrapetrik/jpexs-decompiler
发布下载：https://github.com/jindrapetrik/jpexs-decompiler/releases

GUI 方式：用 FFDec 打开 v5880.swf，选择“工具 → 导出 → 导出脚本”，
或右键选择导出 AS3。
命令行示例（Windows）：
    ffdec.bat -export script .\as_out .\v5880.swf

导出的 .as 文件可用于对照配置表结构；本工具只解析配置，不修改主文件。
